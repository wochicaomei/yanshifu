# 宴师傅（YanShiFu）

宴师傅是一款专为家宴团队、流动厨师、宴席承办团队打造的数字化经营工具。

我们希望帮助家宴从传统的微信沟通、纸质记录模式，升级为更加专业、高效、品牌化的服务模式。

## 产品愿景

让每一位家宴师傅都拥有属于自己的数字化经营平台。

通过简单易用的小程序，帮助师傅管理档期、展示菜单、打造品牌形象，让客户更方便了解服务内容，也让师傅能够更加专注于做好每一场宴席。

## 核心价值

### 档期管理

帮助师傅记录和管理宴席档期，避免时间冲突，提高接单效率。

### 菜单管理

统一维护宴席菜单、价格及套餐内容，减少重复沟通成本。

### 品牌展示

为每位师傅打造专属品牌主页，展示团队介绍、特色菜单、宴席案例和客户评价，提升专业形象和客户信任度。

### 一键分享

支持将菜单和品牌主页分享给客户，让客户快速了解服务内容，提高沟通效率。

## 产品定位

宴师傅不是一个复杂的ERP系统。

我们希望打造的是：

> 师傅每天愿意打开，客户愿意收藏和分享的家宴经营工具。
